# Excel Restaurant Analysis

An Excel-based restaurant data analysis project focused on data cleaning, data quality checks, exploratory analysis, and dashboard development.

## Tools Used

- Microsoft Excel

## Project Workflow

- Raw data preparation
- Data cleaning and quality checks
- Data validation
- Exploratory data analysis
- Pivot table analysis
- Dashboard and insights

## Project Files

- `Raw Data/` – Original source datasets
- `Working Data/` – Data preparation and analysis workbooks
- `Screenshots/` – Project dashboard screenshots
